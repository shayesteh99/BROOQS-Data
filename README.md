# BROOQS-Data
All data analyzed in the paper "BROOQS: Spectral Methods Resolve Level-1 Hybridization Cycles without Tests of Symmetry". We analyzed three simulated datasets and two biological datasets.

## 1) Fixed-ILS dataset (Wilson and Warnow 2026):
The original dataset is published by [Wilson and Warnow 2026](https://www.biorxiv.org/content/10.64898/2026.02.01.703143v1), and is available [here](https://databank.illinois.edu/datasets/IDB-6892704). See []() for a detailed description of each file in this directory.

## 2) Varying-ILS dataset (Dai et al. 2026):
The original dataset is published by [Dai et al. 2026](https://www.biorxiv.org/content/10.1101/2025.11.05.686850v3), and is available [here](https://datadryad.org/dataset/doi:10.5061/dryad.cjsxksnnp). See []() for a detailed description of each file in this directory.

## 3) Varying-ILS+GTEE dataset (Kalbow et al. 2026): 
The original dataset is published by [Kalbow et al. 2026](https://www.biorxiv.org/content/10.1101/2025.05.05.652278v4), and is available [here](https://datadryad.org/dataset/doi:10.5061/dryad.h44j0zq0b). See []() for a detailed description of each file in this directory.
